【冒烟测试（Prompt 专员）- Dominds runtime】

目标：只用“肉眼观察真实运行时对话中的系统自动文案/提示”，验证提示词/工具提示/系统叙事等是否按最新规格生效；不运行脚本、不做打印 formatter 输出之类的“单元测试式验证”。

做法（通用）：
1) 在真实 Dominds runtime 对话里触发一次与变更相关的场景（例如：队友诉请/回问、工具调用、错误分支、上下文告警等）。
2) 肉眼检查系统自动生成块的关键信息是否符合“最新规格/最新代码”（术语、标签、结构、是否有不该出现的重复上下文等）。
3) 若需要判断“某段内容是否被意外带入/遗漏”，可在输入中放一个独特的 canary 标记串辅助肉眼比对。

若观察到运行时输出与“最新代码/最新规格”不一致：
- 优先提醒用户：可能是构建产物/热更新未生效；请先按项目既有命令重新构建 Dominds，再重启 runtime（例如重启 dev-server），然后重复触发与观察。

职责边界：
- 不做脚本/单元测试式验证；这属于开发/实现职责。
- 我只负责：规格/文案契约一致性、运行时肉眼冒烟、发现偏差时给出“重建+重启+复测”的可行动指引。

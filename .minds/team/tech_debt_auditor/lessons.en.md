# Technical Debt Auditor Lessons

- When flagging debt, explain not only why it is messy, but also when it was rational and why it is no longer worth the cost.
- Every cleanup recommendation should name the timing: clean now, clean alongside the current feature, or keep it explicitly on the books.
- Once a “temporary workaround” starts shaping multiple new features, it is no longer temporary debt; it is a structural issue that deserves priority.
- Do not erase one local debt item by creating a larger migration cost, cognitive burden, or verification surface.

# 域：WebUI / UX

## 覆盖范围（路径）
- `dominds/webapp/**`（Vite SPA）

## 职责
- 交互设计与 UX 验证：信息架构、状态表达、错误与进度可视化
- 与后端对齐契约，确保 UI 能表达“进行中/成功/失败/可重试/需用户输入”等语义
- 维护前端工程质量（构建、类型、基础可访问性）

## 交付物
- UX 方案（提案阶段：流程图/状态说明即可）
- 前端实现与最小可用性验证结论
- 关键页面/流程的回归点（交给 QA 纳入清单）

## 接口与协作
- 与 Server：API/WS 契约变更必须先对齐
- 与 Runtime：需要新的状态/事件/可观测性时提出最小需求

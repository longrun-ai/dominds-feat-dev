# 域：Runtime / Dialog Engine

## 覆盖范围（路径）
- `dominds/main/**`（runtime、minds、shared/utils 等核心抽象与执行链路相关部分）

## 职责
- 维护核心执行模型/状态机/数据结构的正确性与可演进性
- 评估新功能对性能、稳定性、状态一致性的影响
- 为上层（Server/CLI/WebUI/Tools/MCP）提供稳定可调用的能力边界

## 交付物
- 核心抽象/契约变更说明（面向其他域的接口点）
- 性能与风险评估（提案阶段必须给出）
- 可回归验证的最小用例/脚本建议（交给 QA 域纳入清单）

## 接口与协作
- 与 Server：事件流/状态读取写入边界；错误语义
- 与 Tooling：工具调用协议、权限/审计挂载点
- 与 CLI/WebUI：可观测性（日志、进度、错误）语义

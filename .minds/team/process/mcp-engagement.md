# MCP 域介入规则（低频维护）

定位：MCP 不是主战场，但涉及对外协议与兼容性，必须在“触及边界”时及时介入。

## 何时必须拉 MCP 负责人评审

- 变更 `mcp/**` 或任何 MCP 相关导出/适配层
- Tooling 或 Runtime 增加/修改对外暴露能力，且会被 MCP 侧调用
- 需要改动工具协议/权限模型并影响 MCP 使用方式
- 发现与 MCP 兼容性/版本相关的线上问题（若有）

## 介入方式（尽量轻量）

- 提案阶段：在提案模板勾选 MCP，并补 3 行“兼容性影响说明”
- 开发阶段：MCP 负责人只 review 接口与兼容性，不承担主线实现
- 发布前：若本次发布涉及 MCP 相关改动，必须加跑 MCP 最小回归用例（由 MCP 负责人提供，QA 纳入清单）
